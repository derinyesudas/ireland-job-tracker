Only show jobs she can actually apply for, and lock the board

Adds scraper/eligible.py: reads each advert and decides eligibility on seven
grounds, quoting the sentence that decided it. Nothing is deleted - a blocked
job is published marked, so a wrong rule is visible rather than silent.

  discipline        out-of-field roles (engineering, clinical, legal, trades,
                    marketing, actuarial, software) leave the main board
  qualification     blocks only when a credential she lacks is REQUIRED;
                    an employer who funds the QFA is a bonus, not a barrier
  degree subject    open lists ("or related discipline") are not walls
  years             4+ blocks, 3 flags; programme length is not experience
  programme length  commitments over two years
  current student   internships and co-ops needing enrolment
  language          a required language she does not speak

Locks the published board. site/data is encrypted with the existing vault
format, so the browser opens it with WebCrypto and a visitor without the code
can fetch every published file and see nothing. lock_board fails the deploy if
any readable JSON survives. add_board_code.py gives the board its own holder,
so the code typed into a browser is never the passphrase that opens the vault.

Verified in a real browser against real encrypted data: wrong code rejected,
right code opens in ~350ms, blocked jobs off the default board and behind the
Can't apply chip with the advert's own words underneath, both themes.
